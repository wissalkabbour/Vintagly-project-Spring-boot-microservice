Vintagly : Vintage Marketplace
Overview :

Vintagly is a web platform dedicated to lovers of vintage and second-hand objects.
It connects passionate sellers with buyers looking for unique, authentic items.
The platform ensures quality through an admin validation process for sellers and provides a smooth, secure shopping experience.
Vintagly follows a modular and scalable architecture based on microservices.

Main Features:

👤 Client Space

Browse a catalog of vintage articles.

Add items to a personal cart.

Place orders and receive invoices.

Submit a request to become a seller.

🧰 Seller Space

Once approved, sellers can create and manage their own articles.

Add images, descriptions, and prices for each product.

Track validation and publication status.

🛡️ Admin Space

Review and validate seller requests.

Manage categories and articles on the platform.

Monitor transactions and ensure platform integrity.

...Vintagly was created as part of an academic project to simulate a real-world marketplace for vintage objects.
It emphasizes simplicity, authenticity, and trust between buyers and sellers.
